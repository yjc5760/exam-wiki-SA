## SA-2005-1　剛架（A 固定、C 滾支）最小功法求各桿彎矩

**題意**：B(0,0) 角點剛接；A(8,0) 固定；C(4,−4) 滾支（垂直反力）；B 點 10 N 向下；不計軸力、剪力。附圖核對一致。

**解法**：贅餘 R_C。U = ∫M²/2EI，∂U/∂R_C = 0。
I = 20⁴/12 = 13,333 cm⁴、EI = 1.333×10¹⁰ N·cm²＝1.333×10⁶ N·m²（兩桿 EI 相同，彎矩與 EI 無關）。

**結果**：
- R_C = 10(2 − √2) = **5.858 N**（向上）；A：R_A = 4.142 N、M_A 反力矩 56.57 N·m
- BC 桿：C 端 0 → B 端 **23.43 N·m**（= 80 − 40√2），外側（左下側）受拉，線性
- BA 桿：B 端 **−23.43 N·m**、A 端 **−56.57 N·m**（= −40√2），全長上緣受拉，線性
**盲分類**：主 SA-U2-1（同意索引）。

## SA-2006-1　梁＋桁架組合橋，J 點垂直變位

**題意**：梁 A–E 長 40 m，滾支 A(0)、B(10)、D(30)，E 自由；10 kN 於 x = 15、25 m；桁架上弦 F–G（F、G 鉸支），下弦 H(10)、J(20)、K(30)，深 10 m，13 桿；E、I、A 全部相同常數。二度靜不定。

**解法**：贅餘取梁 R_A＝X 與 G 水平反力 H；U = ∫M²/2EI（梁）＋ΣN²L/2EA（桁架），∂U/∂X = ∂U/∂H = 0（sympy 閉式）；Δ_J 以單位載重法於 G 改滾支的桁架上求。

**結果**：答案依 **r = EA/EI（1/m²）** 而變，考卷沒有給比值，只能寫成 Δ_J = g(r)/EA：

| EA/EI | R_A (kN) | Δ_J·EA (kN·m) |
|---|---|---|
| → 0（梁極柔） | 5.858 | 341.4 |
| 0.01 | 4.818 | 366.5 |
| 0.1 | 0.591 | 468.6 |
| 1 | −3.018 | 555.7 |
| 10 | −3.671 | 571.5 |
| → ∞（桁架極剛，梁＝剛性支承連續梁） | −15/4 = −3.75 | **237.5(1 + √2) = 573.4** |

- 實際斷面 EA/EI = 1/r_g²（r_g 迴轉半徑，量級 10–100 /m²），落在「→∞」極限，故**實用答案 Δ_J ≈ 573.4/EA（向下）**，梁彎曲的影響 < 0.1%
- 不論 r：T2J 豎桿 = 0、KG = +10√2 kN（拉）
- 不確定處：考卷只說 E、I、A 常數；若解析以剛性支承連續梁求 R_B、R_D（R_A = −3.75 向下拉住梁端），與上表極限一致；若把 A 當單向支承（不能受拉）則結果不同
**盲分類**：主 SA-U2-1（同意；未指定方法）。

## SA-2008-3　剛架（A 滾支、C 固定）最小功法彎矩圖

**題意**：A(0,0) 滾支（垂直反力）、B(6,0) 剛接、C(10.5,−6) 固定；AB 全長 2 kN/m；BC 斜長 7.5 m、無載重；EI 常數。

**解法**：贅餘 R_A；M_AB = R_A x − x²；BC 只受垂直力，M 沿水平投影線性，ds = (7.5/4.5) du；∂U/∂R_A = 0。勁度法驗算一致；計入軸向變形（EA/EI = 10³）R_A 只變 0.001%。

**結果**：
- R_A = 3888/529 = **7.350 kN**；C：V_C = 4.650 kN、H_C = 0、M_C 反力矩 12.83 kN·m
- AB：M_A = 0，最大正彎矩 **13.50 kN·m** 於 x = 3.675 m，M_B = 4284/529 = **+8.098 kN·m（下緣／內側受拉）**
- BC：B 端 8.098（內側受拉）→ 線性 → C 端 6786/529 = **12.83 kN·m（外側受拉）**；反曲點距 B 沿桿 2.90 m（水平 1.741 m）
**盲分類**：主 SA-U2-1（同意）。

## SA-2014-4　剛架（A 固定、D 滾支）最小功法求 C 轉角

**題意**：A(0,0) 固定、C(12,0)、D(12,−12) 滾支（只有垂直反力）；AC 為 EI、CD 為 2EI，EI = 1000 kN·m²；B(6,0) 20 kN↓。

**解法**：D 滾支不能提供水平力 → CD 柱只有軸力、彎矩為零，結構等同 A 固定、C 端垂直支承的單跨梁。贅餘 R_D，最小功；勁度法驗算一致。

**盲分類**：主 SA-U2-1（同意）。

## SA-2016-3　已知桿端彎矩求 C 點變位

**題意**：A、D 固定；AB 斜長 10 m、BC 12 m（2 kN/m）、CD 20 m；題給 M_AB = −23.2、M_BC = 5.63、M_CD = −25.3、M_DC = −17.0 kN·m；考卷沒有給 AB 傾角與正負號規約；「C 點的變位」沒有指定方向。

**正負號規約辨識**：以勁度法試解不同 AB 傾角，**AB 與水平夾 60°（水平 5 m、垂直 8.66 m）時，順時針為正的端彎矩 M_AB = −23.16、M_BC = +5.63、M_CD = −25.29、M_DC = −17.05**，與題給四值完全吻合 → 題給為傾角變位法規約（作用於桿端、順時針為正），M_BA = −5.63、M_CB = +25.3。

**解法（只用 CD 柱，不需 AB 傾角）**：D 固定、θ_D = 0，不計軸向變形 → C 垂直位移 0。
M_CD = (2EI/20)(2θ_C − 3ψ)、M_DC = (2EI/20)(θ_C − 3ψ) → θ_C = −83/EI、ψ = 29/EI（順時針）。

**結果**：
- **θ_C = 83/EI（逆時針）**
- **水平 Δ_C = 20ψ = 580/EI（向右）**
- **垂直 Δ_C = 0**
- 以 60° 幾何全剛架勁度法：Δ_C = 587.4/EI →、θ_C = 82.4/EI 逆時針（差異來自題給彎矩只到小數一位；以題給值求為 580/EI、83/EI）
**盲分類**：主 SA-U2-1 可（單位載重法／虛功）；亦可歸 SA-U2-3（以傾角變位式反求）。同意索引。

## SA-2017-2　兩端固定、內鉸 c 之梁，最小功法求固定端彎矩

**題意**：a、b 固定，c 內鉸距 a 為 m、距 b 為 n（m + n = L），滿跨 w，EI 定值。

**解法**：贅餘取內鉸剪力 V（右段作用於左段、向上為正），U = ∫M²/2EI，∂U/∂V = 0：
V = 3w(m − n)(m² + n²) / [8(m² − mn + n²)]

**結果**（兩端皆負彎矩、上緣受拉）：
- **M_a = −wmL(m² − 2mn + 3n²) / [8(m² − mn + n²)]**；a 端支承反力矩**逆時針**
- **M_b = −wnL(3m² − 2mn + n²) / [8(m² − mn + n²)]**；b 端支承反力矩**順時針**
- 驗算：m = n 時 M_a = M_b = −wm²/2（兩懸臂，V = 0）；m = 0.43L 時 M_a = −0.1359wL²、M_b = −0.1048wL²
**盲分類**：主 SA-U2-1（同意）。

## SA-2018-3　梁柱＋只受拉纜索，最小功法求纜索力與梁彎矩圖

**題意**：梁 A(0)–B(5)–C(10)–D(15)，柱 C–G 5 m（G 固定），纜索 A–E、B–F 垂直 5 m 只受拉；EI = 1000、EA_纜 = 500 kN；D 點 100 kN↓；忽略梁柱軸向、剪切變形。

**解法**：先假設兩索皆有效（二度靜不定）→ AE 得 **−0.44 kN（壓）**，違反只受拉條件 → AE 鬆弛（0），重解一度靜不定（贅餘 T_BF）：
U = [∫(T x)²dx + ∫(100x)²dx]/2EI ＋ (500 − 5T)²·5/2EI ＋ T²·5/2EA，∂U/∂T = 0。勁度法驗算一致；重解後 A 點下移，AE 確實不受拉。

**結果**：
- **T_AE = 0（鬆弛）**、**T_BF = 3750/53 = 70.75 kN（拉）**
- 梁彎矩（上緣受拉為負）：AB 段 **0**；BC 段 B 0 → C **−353.8 kN·m** 線性；CD 段 C **−500 kN·m** → D 0
- 參考：柱 CG 常數彎矩 146.2 kN·m、軸壓 170.75 kN
**盲分類**：主 SA-U2-1（同意）。

## SA-2019-1　漸進破壞桁架，極限外力與 P–U_B 定性圖

**題意**：D(0,9)、B(12,9)、C(0,0) 鉸支、A(12,0) 滾支；桿 DB、CA（水平 12）、DC、BA（垂直 9）、DA、CB（對角 15）；B 點 P→；拉強度 1250，壓強度 對角 144／水平 225／垂直 400 kN；達強度後勁度 0，張桿維持強度、壓桿內力歸零。

**解法**：事件對事件增量分析（EA 相同）。

| 階段 | P (kN) | 事件 | 內力（DB, CA, DC, BA, DA, CB） |
|---|---|---|---|
| 彈性 | 0 → **327.4** | 對角 **DA 壓到 144 挫屈** | 115.2, 115.2, 86.4, −159.2, −144, 265.3 |
| DA 退出（P 不變重分配） | 327.4 | 剩下靜定：D 節點兩桿為零，CA = 0 | 0, 0, 0, −245.6, 0, 409.3 |
| 第二段 | 327.4 → **533.3** | 垂直 **BA 壓到 400 挫屈** → 機構 | 0, 0, 0, −400, 0, 666.7 |

- **極限外力 P_u = 1600/3 = 533.3 kN**（CB = 1.25P ≤ 1250 未降伏，BA = −0.75P 控制）
- P–U_B 定性圖：第一段直線，斜率 0.0541EA（U_B = 6048/EA 時 P = 327.4）；DA 挫屈時荷重控制下 U_B 跳到 9331/EA（位移控制下 P 降到 212 kN），之後斜率降為 0.0351EA（剩餘結構的直線通過原點）至 U_B = 15200/EA、P = 533.3；BA 挫屈後形成機構，P 驟降至 0（位移無限增加）

## SA-2022-1　由彎矩圖反推彈簧力、c、e 點位移

**題意**：d(0) 滾支、c(5) 彈簧 k = 6000 kN/m（下端 e 沉陷 Δe）、b(10) 內鉸、a(15) 固定；c、b 各 72 kN↓；EI = 250,000 kN·m²；彎矩圖 M_c = +120（正彎矩）、M_a = −480 kN·m。

**解法**（靜力＋變位，不需重解靜不定）：
- d–b 段：M_c = 5R_d = 120 → R_d = 24 kN；對 b 取矩：10R_d + 5F_s − 72×5 = 0 → **彈簧力 F_s = 24 kN（受壓，向上頂 c）**

- 彈簧壓縮 24/6000 = 0.004 m → **v_e = Δe = 0.012 − 0.004 = 0.008 m = 8 mm（向下）**
**盲分類**：主 SA-U2-1（同意；未指定方法）。
