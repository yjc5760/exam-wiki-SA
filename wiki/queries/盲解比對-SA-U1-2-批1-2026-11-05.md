### SA-2010-1　❌ 分歧-答案改變（L1 看圖）

| 桿 | 舊解 | 盲解 |
|---|---|---|
| AC | 0（零桿） | **−14.14 kN ＝ −10√2（壓）** |
| BF | +30 kN（拉） | **+10 kN（拉）** |
| DE | −60 kN（壓） | **−30 kN（壓）** |

- 反力兩邊一致（B_x 30←、G_x 30→、G_y 30↑）。
- **錯在節點 G**：舊解 §4 步驟 2 寫「G 點連接 CG（垂直）與 DG（斜向）兩桿件」，漏了水平桿 **GH**（判讀清單 #2 已列 GH，附圖 G–H 底弦清楚可見）。少一個未知數後得到 F_CG = 0 → F_AC = 0 → F_AB = F_AE = 0，連鎖使 BF、DE（斷面法時把 AB、AE 當零）全錯。
- 舊解本身也不自洽：以其 AC = AB = AE = 0 往下推，節點 B → BF = 30、節點 F → HF = 30√2、節點 H → DH = 0、GH = 30、節點 G → GD = −60√2、CG = 30，回到節點 C 得 AC = 30√2 ≠ 0，矛盾。
- 盲解兩條路徑：①全桁架 13 桿＋3 反力聯立（秩 16 滿）；②手算節點 C、A、B、F、H、G、D、E 全部平衡殘差 0，並以左半斷面對 H 取矩：−120 + 80（AB = −20）− 20（AE = +10√2）− 2F_DE = 0 → F_DE = −30 ✓。
- 盲解全部桿力：AB −20、AC −10√2、AE +10√2、EB −10√2、BF +10、CD +10、DE −30、EF −10、CG −10、GD −20√2、DH +20√2、GH −10、HF +10√2（kN）。CG、AC、AB、AE 都不是零桿；本題沒有零桿。
