### SA-2008-4　❌ 分歧-答案改變（算術：剪力正負號）

| 項目 | 舊解 | 盲解 |
|---|---|---|
| θ_B、θ_C | 3/EI（順時針）、−6/EI | 同（−3/EI、+6/EI 逆時針為正） |

| BC 最大正彎矩 | **0.125 kN·m，距 B 2.5 m** | **3.125 kN·m，距 B 3.5 m** |
| §5 彎矩圖 | 柱頂 3.0、柱底 1.5（與 §4 步驟 5 矛盾）；梁極值 0.125 @ 2.5 m | 柱頂 3.0（外側受拉）、柱底 1.5（內側受拉）、柱反曲點距 A 4/3 m；梁 3.125 @ 3.5 m |

- 錯因：B 端為負彎矩（梁頂受拉）3 kN·m，簡支剪力 3 再加 3/6 = 0.5 → V_B = 3.5；舊解把端彎矩的符號帶反成 3 − 0.5 = 2.5。舊解自己先算出 3.5，又以「Python script result 2.5 是正確的」改回錯值。
- 兩條獨立路徑一致：①勁度法回算 V_B = 3.5；②靜力：M(x) = 3.5x − x²/2 − 3，dM/dx = 0 → x = 3.5、M = 3.125。檢核 M(6) = 21 − 18 − 3 = 0 ✓（舊解 M(x) = −3 + 2.5x − x²/2 在 x = 6 得 −6 ≠ 0）。
- 柱端彎矩：步驟 5 的 0.75／1.5 不滿足節點 B 平衡（M_BA + M_BC = 1.5 − 3 ≠ 0）；§5 寫的 3.0／1.5 才對，兩處互相矛盾。
- §4 步驟 5–6 有大量生成殘留（「Wait, M_CB should be 0!」「Let's check Python code logic」、英文自問自答），勘誤時整段重寫。
- 屬推導／算術、證據明確（兩條路徑一致），可直接進勘誤。考卷要求「繪彎矩圖並標示最大與最小值」，這題的答案就是這兩個數，影響得分。
- **回考卷看**：不需要（題意無爭議）；可直接看舊解 §4 第 136–156 行。
