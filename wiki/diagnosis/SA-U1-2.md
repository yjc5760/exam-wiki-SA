# SA-U1-2 題型診斷｜靜定結構之分析

> **核心命題：** 靜定結構的內力由「幾何＋平衡」唯一決定，與剛度（$EI$、$EA$）無關；
> 剛度只在要算「位移」時才登場。
>
> 完整原理說明見觀念講義：[lecture-SA-U1-2.html](../../study/lecture-SA-U1-2.html)（[PDF](../../study/lecture-SA-U1-2.pdf)）
> 出題統計與逐題索引見速查頁：[study-SA-U1-2.html](../../study/study-SA-U1-2.html)
>
> 題數：主分類 17 題、副分類 3 題（2002–2024），為全科 10 個子項中出題最多者。

## 決策樹

### 第一問：靜定嗎？（30 秒，決定接下來 25 分鐘走哪條路）

先數 $r$、$c$、$m$、$j$，再選公式：

| 對象 | 公式 | 用時機 |
|------|------|--------|
| 平面桁架 | $d = m + r - 2j$ | 只有軸力桿，每節點 2 個方程 |
| 平面剛架（完整式） | $d = 3m + r - 3j - c$ | 有閉合環，或桿件多而節點少 |
| 樹狀梁／剛架（簡化式） | $d = r - 3 - c$ | 無閉合環時最快，考場首選 |

$m$＝桿件數，$j$＝節點數，$r$＝支承反力分量總數，
$c$＝內部釋放（連兩桿的內鉸 $c=1$；連 $k$ 桿的複鉸 $c=k-1$）。

```
        ┌─ d < 0 ──→ 你漏看東西了（見下方「隱藏條件三型」），補上後重數一次
        │
數 d ───┼─ d = 0 ──→ 靜定，繼續走第二問              ← 本子項主場
        │
        └─ d > 0 ──→ 離開本子項，轉 SA-U2（力法／位移法）
```

**特例：瞬間機構。** 靜不定度是**代數**判定，看不見「三個反力作用線交於一點或平行」這種**幾何**退化。
$d = 0$ 仍須用眼睛確認幾何不退化。

### 第二問：要內力，還是位移？

```
                    ┌─ 內力 / 內力圖 ──→ 走「平衡路線」（第三問 A）
題目問什麼？ ───────┤
                    └─ 位移 / 轉角 ────→ 走「變形路線」（第三問 B）
```

判斷副作用：如果是內力路線，題目給的 $E$、$I$、$A$ **一律用不到**，不要浪費時間讀。

---

### 第三問 A：結構型式？（內力路線）

```
             ┌─ 桁架 ──→ ① 整體平衡求反力
             │           ② 零力桿掃蕩（兩法則）
             │           ③ 目標桿周邊桿多 → 截面法（Ritter）
             │              目標桿周邊桿少 → 節點法
結構型式？ ──┤
             └─ 梁／剛架 → ① 有內鉸？從內鉸切分離體
                          ② 先解附屬結構，再反向施力於主結構
                          ③ 用 w–V–M 微分關係推形狀，只算關鍵點
```

**節點法 vs 截面法的唯一選擇標準**

| | 節點法 | 截面法（Ritter） |
|---|---|---|
| 可用條件 | 該節點未知桿力 ≤ 2 | 該截面切斷未知桿 ≤ 3 |
| 最適合 | 靠近支承／邊界、幾何單純、要「全部桿力」 | 深在結構內部、只要「指定幾根桿」 |
| 失效情境 | 複雜節點（K 型桁架的中節點連 4 桿） | 找不到只切 3 根桿的截面 |
| 破局技巧 | — | 先用截面法求遠端弦桿，再回頭做節點法 |

**Ritter 力矩中心的選法：放在其餘兩根未知桿的交點上，一式一未知數。**

- 要下弦 → 對上節點取矩
- 要上弦 → 對下節點取矩
- 要腹桿 → 用 $\Sigma F_y = 0$（上下弦水平時）；不平行時取上下弦延長線交點
- 力臂算不清 → 用解析幾何的「點到直線距離公式」，不要目視估計

### 第三問 B：變形的成因是什麼？（位移路線）

```
                      ┌─ 只有外力 ──→ 單一直梁 → 共軛梁法
                      │               （要找最大位移位置最快：令共軛梁 V = 0）
變形是誰造成的？ ─────┤               桁架／剛架 → 單位力法
                      │
                      └─ 含支承沉陷 / 溫差 / 製造誤差 ──→ 廣義虛功（必用）
```

**廣義虛功方程式（一式吃下四種成因）**

$$1\cdot\Delta \;+\; \sum_j \bar R_j\,\Delta_j \;=\; \sum_i \bar n_i\, e_i$$

$$e_i = \underbrace{\frac{N_i L_i}{EA}}_{\text{外力}} + \underbrace{\alpha\,\Delta T_i\, L_i}_{\text{溫度}} + \underbrace{\delta_i}_{\text{製造誤差}}$$

**符號約定只需記一件事：全部以「虛擬單位力的方向」為正。**
先定好方向（例如向下為正），$\bar R_j$、$\Delta_j$ 一律照這個方向定正負；$\bar n_i$、$e_i$ 伸長為正
（製造誤差「過長」為正、升溫為正）。

**四個步驟（順序不可換）**

1. 確認靜定 ⟹ $N_i = 0$ ⟹ **不要算 $NL/EA$**（題目給的 $E$、$A$ 是誘餌）
2. 先用「剛體位移直線」獨立算出沉陷造成的位移
3. 再用虛功式核對 $\sum \bar R_j \Delta_j$ 項的符號是否給出同一個數
4. 剩下的 $\sum \bar n_i e_i$ 就是純桿件變形貢獻

第 2、3 步是**兩條互相獨立的路徑**，只花 30 秒卻能救回符號錯造成的整題失分。
實例：[[SA-2024-2]] 中 B 不動、F 下沉 12 mm、跨距 16 m，
$\Delta^{\text{rigid}}(x) = 12\cdot\frac{x-4}{16}$，C 點得 3 mm、E 點得 9 mm；
虛功式的 $\bar R_F$ 項恰好給出同一組數字。

---

### 補充問：題目問的是「求某力使位移為零」或「求最小 $EI$」？

一律是**疊加原理**題，不是新方法：

1. 把成因分兩堆：不含未知量的先算成一個純數字，含未知量的保留為線性函數
2. 令兩堆之和 = 0（或 = 容許值），解出未知量

適用：[[SA-2015-1]]（求 $T$）、[[SA-2023-1]]（求 $P$）、[[SA-2024-1]]（求最小 $EI$）

## 隱藏條件三型（算出 $d < 0$ 時往這裡找）

國考不會出機構。$d < 0$ 就是出題者在提示你漏看了約束。

| 型 | 觸發信號 | 真相 | 出處 |
|----|---------|------|------|
| ① 繫索 | 圖上有虛線連接兩支承 | 是**拉力構件**（tie rod），必須計入 $m$。無它則 $m+r<2j$ 成為機構，且節點 A 有 5 個未知力，節點法一開始就卡死 | [[SA-2002-2]] |
| ② 三鉸拱 | 桁架中央缺底弦桿 | 兩端**皆為鉸**（4 個反力）；第 4 式來自「左右兩半各對中央鉸 $\Sigma M = 0$」。誤設 $A_x = 0$ 會在目標節點產生 $\Sigma F_x$ 與 $\Sigma F_y$ 互相矛盾的結果 | [[SA-2013-1]] |
| ③ 支承方向 | 滾支承畫在**垂直牆面**上 | 反力垂直於**接觸面**，此時只有水平分量。慣性假設「滾支承給垂直反力」會全盤皆錯 | [[SA-2010-1]] |

**另外兩種偽裝（不改變 $d$，但會讓人誤判靜不定）**

- **彈簧支承**：彈簧＝**1 個**反力分量，與滾支承同級；$k$ 只用來算 $\Delta = R/k$。
  [[SA-2004-3]]：A 固定端(3) ＋ C 彈簧(1) = $r=4$，B 內鉸 $c=1$ ⟹ $d = 4-3-1 = 0$，是**靜定**。
- **「平面構架」字樣**：某桿自由端只受一力、無其他橫向束制 ⟹ 可**降維**，把力平移到節點成為集中力偶。
  [[SA-2023-1]] 的垂直桿 CF（長 4 m、F 受 $P$）等效於在 C 點加順時針力偶 $M_C = 4P$，整題退化成一根連續梁。

## 五條因果鏈（能用嘴巴講出來才算會）

1. **靜定 ⟹ 免疫**：約束恰好 → 支承移動時結構可自由調整位置 → 無額外應變 → 應力為零 → 內力為零 → $NL/EA$ 消失 → 位移只剩剛體位移＋原有桿長變化。
2. **內鉸 ⟹ 切點**：內鉸 $M=0$ → 多一個方程式 → 可切成兩個分離體 → 先解未知數少的附屬結構 → 反向施力於主結構 → 解完全部反力。
3. **位移倒流**：附屬結構把力交給主結構 → 主結構變形 → 交界點下沉／轉動 → 附屬結構被迫剛體運動 → 真實位移 = 剛體位移 ＋ 自身彈性變形。
4. **桁架破局**：節點未知數 > 2 卡死 → 改切一個只斷三根桿的截面 → 對其餘兩桿交點取矩 → 一式一未知數 → 求出遠端弦桿 → 原節點未知數降到 2 → 節點法復活。
5. **Ritter 的物理**：$F_{\text{弦}} \cdot d = M_{\text{斷面}}$ → 桁架越深弦桿力越小 → 弦桿力影響線 = $M$ 影響線 ÷ 定值 $d$ → 最大軸力發生在最靠近該斷面的載重位置。

## 高頻失分點

| # | 觸發信號 | 錯誤思維 | 正確認知 | 出處 |
|---|---------|---------|---------|------|
| 1 | 題目給了 $E$、$A$（或 $EI$）卻只問位移成因 | 「給了就要用」 | 靜定＋非外力成因 ⟹ $N=0$，這兩個數是誘餌 | [[SA-2024-2]] |
| 2 | 附屬結構要算位移 | 只算自身彈性變形 | 必加交界點造成的**剛體位移**，且要先加再找極值 | [[SA-2024-1]] [[SA-2004-3]] |
| 3 | 內鉸兩側各有一個集中力矩 | 「方向相反，抵銷」 | 作用在**不同分離體**上，各自進入各自的 $\Sigma M=0$ | [[SA-2002-1]] |
| 4 | 固定端反力矩是順時針 | 「順時針＝負彎矩」 | 正負看**受拉側**；左端順時針 ⟹ 底部受拉 ⟹ 正彎矩 | [[SA-2012-1]] |
| 5 | 內鉸的水平傳遞力算出 0 | 「柱子全段都有彎矩」 | 柱頂無水平力且該段無載重 ⟹ 該段內力恆為零 | [[SA-2004-1]] |
| 6 | 集中力矩處 | 「V 圖也要跳」 | $M$ 跳躍、$V$ 完全不變；跳躍前後斜率相同 | [[SA-2002-1]] |
| 7 | 均佈載重段找最大彎矩 | 「在跨中」 | 在 $V(x)=0$ 之處，一定要解出來 | [[SA-2004-1]] [[SA-2024-1]] |
| 8 | 外力全部垂直，結構有斜桿 | 「沒有水平位移」 | 斜桿的長度約束會把垂直位移翻譯成水平位移；**平衡與諧合是兩回事** | [[SA-2003-2]] |
| 9 | 某桿是零力桿 | 「該方向不會動」／「可以拆掉」 | 零力桿仍提供長度約束（生位移）、挫屈束制、活載換位後受力、冗餘度 | [[SA-2003-2]] [[SA-2017-1]] |
| 10 | 梁段剛度分成 $2EI$ 與 $EI$ | 共軛梁載重統一除以 $EI$ | 載重 $=M/EI$ 要**分段**；先在 BMD 上標註剛度區域 | [[SA-2012-1]] |
| 11 | 共軛梁的內部支承／內鉸 | 憑印象配對 | 回歸「位移↔彎矩、轉角↔剪力」逐條推：內部支承↔內鉸、內鉸↔內部支承 | [[SA-2012-1]] |
| 12 | 虛功式含支承沉陷項 | 硬記符號 | 先用剛體位移直線算一次，用它反推 $\sum\bar R_j\Delta_j$ 的正負 | [[SA-2024-2]] |
| 13 | 沉陷給 mm、$EI$ 給 kN-m² | 直接代入 | 統一單位（m、kN）；3 mm 要寫 0.003 m | [[SA-2023-1]] |
| 14 | 桁架斜桿長度不漂亮（$\sqrt{433}$、$2\sqrt{13}$） | 湊成 3-4-5 | 老實用方向餘弦；力臂改用點到直線距離公式 | [[SA-2014-1]] [[SA-2017-1]] |
| 15 | 算出來繫索是壓力 | 照抄 | 繫索只能拉 ⟹ 一定是符號錯，免費驗算點 | [[SA-2002-2]] |
| 16 | 懸空節點只連兩桿，其一連到有載重處 | 「這根桿把載重吊上去了」 | 問「這個懸空節點自己平衡得了嗎？」不能 ⟹ 兩桿皆零（無效懸吊） | [[SA-2016-4]] |
| 17 | 要畫柱的 BMD | 沿用梁的上／下側判斷 | 剛節點處受拉側會翻面，柱要獨立判斷左／右側受拉 | [[SA-2002-1]] [[SA-2004-1]] |

## 零力桿兩法則（不要背，推得出來）

證明只有一行：**選一個聰明的投影方向，讓大部分未知力消失。**

| 法則 | 條件 | 結論 | 投影方向 |
|------|------|------|---------|
| 二桿節點 | 無外力、無支承，僅連兩根**不共線**桿 | 兩桿皆零 | 垂直於其中一桿 → 只剩另一桿的分量 |
| 三桿含共線對 | 無外力、無支承，三桿中兩根共線 | 第三根（不共線者）為零；共線兩桿力相等 | 垂直於共線方向 → 兩共線桿無分量 |

## 索引異常提醒

**[[SA-2008-3]] 的 `primaryTopicId` 掛在 SA-U1-2，但名實不符。**
題目明文要求「以最小功法（least work）計算」，結構為**一度外靜不定**剛架
（A 滾支承 1 ＋ C 固接 3 = 4 個反力，$d = 4 - 3 = 1$）。
讀它時請視為 **SA-U2-1（最小功法）** 的題目。它對本子項唯一的貢獻是兩個技術動作：
斜桿段 $ds = \tfrac53 dx$ 的轉換、以及剛節點的彎矩連續性檢查。

**[[SA-2010-1]] 掛在 SA-U1-2 的副分類，但內容完全屬於本子項**
（零力桿掃蕩 ＋ 垂直牆滾支承 ＋ 節點法／斷面法混合戰術），值得當主分類題完整做一次。
