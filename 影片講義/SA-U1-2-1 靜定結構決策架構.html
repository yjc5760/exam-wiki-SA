導言

這支影片整理靜定結構分析的總體決策架構。這個單元的招式看起來很多：靜不定度、主附屬結構、零力桿、截面法、共軛梁法、虛功法。其實只要拿到題目，先問自己三個問題，解題路線就唯一確定，公式自然就選對了。

邏輯一：兩條資訊鏈

先講三個底層邏輯。第一個，兩條資訊鏈：內力和位移是完全分開的。

① 內力側：平衡方程式即可解到底

靜定結構的未知力數，剛好等於可用的平衡方程式數。只靠幾何加外力，用水平、垂直、彎矩三條平衡式，內鉸再多一條彎矩等於零，就能一路解出反力，再切自由體求軸力、剪力、彎矩。

$$\Sigma F_x=0,\quad \Sigma F_y=0,\quad \Sigma M=0\qquad(\text{內鉸另加 } M=0)$$

整個過程完全不需要 \(E\)、\(I\)、\(A\)。

② 位移側：變形累積的幾何後果

從已經解出的內力接手，這時候才需要材料和斷面。軸向變形與曲率：

$$e=\frac{NL}{EA},\qquad \phi=\frac{M}{EI}$$

再用共軛梁法或單位力法，沿著桿件把變形累加起來，得到位移 \(\Delta\) 和轉角 \(\theta\)。

重點剛度只影響位移的大小，不影響內力。

邏輯二：非外力成因免疫

第二個邏輯，是第一個的推論：靜定結構對非外力成因免疫。支承沉陷、溫度變化、製造誤差，這三種變形都不是由內力產生的。靜定結構沒有多餘的束制，可以自由跟著變形，只會產生剛體位移，不會產生一絲內力。

非外力成因符號靜定結構的反應
支承沉陷\(\Delta\)可自由變形 → 不產生束制力
內力恆為 0，只有剛體位移
溫度變化\(\alpha\cdot\Delta T\cdot L\)
製造誤差\(\delta\)

這是考場上常見的陷阱。題目給了 \(E\)、給了 \(A\)、也給了溫差或沉陷量，卻只問靜定結構的內力或反力——那些數字全部是誘餌，答案直接是零。只有問到位移，這些數字才派得上用場。

考場陷阱只問靜定結構的內力／反力時，\(E\)、\(A\)、溫差、沉陷量全部是誘餌，答案 = 0；只有問「位移」時才用得到。

STEP 1 靜定判定

第三個邏輯：公式不是死背，而是決策路徑上的工具。接下來照三個步驟走。第一步，判定靜定。

結構型式靜不定度公式備註
平面桁架\(d=m+r-2j\)
樹狀梁／剛架（無閉合環）\(d=r-3-c\)考場首選
有閉合環剛架\(d=3m+r-3j-c\)

式子裡的 \(c\) 是內鉸釋放的束制數。一個內鉸連接 \(n\) 根桿：

$$c=n-1\qquad(\text{一般連兩根桿的內鉸 } c=1)$$

算出 \(d=0\)，是靜定，往下走；\(d>0\) 是靜不定，不在這個單元。

d = 0 只是必要條件支承反力不能全部平行或交於一點，否則幾何不穩定。

算出 d < 0：回頭找隱藏條件

如果算出 \(d<0\)，國考不出機構題，代表你漏看了隱藏條件，立刻檢查四件事：

  1. 中央缺了底弦 → 三鉸拱：兩端都是鉸支，\(r=4\)，中間鉸 \(c=1\)，\(d=4-3-1=0\)，剛好靜定。
  2. 圖上的虛線是拉力繫索：要算進桿數 \(m\)。
  3. 斜面或牆面上的滾支承：反力垂直於接觸面，\(r\) 仍算 1。
  4. 彈簧支承：只算一個反力分量，不影響靜定性；彈簧常數 \(k\) 只拿來算下陷量 \(\Delta=R/k\)。
放行條件確定 \(d=0\)，才進入第二步。

STEP 2 求內力

第二步，問題目要內力還是位移，兩條資訊鏈就在這裡分岔。要內力，只需要平衡；要位移則進入 STEP 3。

帶內鉸的梁或剛架：主結構／附屬結構

先把內鉸切開，問自己：拿掉哪一半，另一半還站得住？站得住的是主結構，站不住的是附屬結構。

順序一定是先解附屬結構，再把內鉸傳遞力反向加到主結構上。畫剪力圖和彎矩圖，用

$$\frac{dV}{dx}=-w,\qquad \frac{dM}{dx}=V$$

推形狀：均布載重段剪力是斜線、彎矩是拋物線，剪力等於零的地方彎矩有極值。彎矩圖一律畫在受拉側。

桁架：固定順序

桁架的固定順序是：求反力 → 掃零力桿 → 截面法 → 節點法。

零力桿規則條件結論
二桿節點節點沒有載重兩根都是 0
三桿節點沒有載重、其中兩根共線第三根是 0

截面法一刀切過三根桿，把力矩中心取在另外兩根未知桿的交點，一條式子就解出一根桿力。

STEP 3 選位移方法

如果題目要位移，位移一定要先有內力才算得動，所以先照第二步把內力解出來，再進入第三步：問變形成因是什麼。

只有外力

單一直梁、或要找最大位移的位置 → 共軛梁法：把 \(M/EI\) 當成彈性載重放到共軛梁上，共軛梁的剪力就是轉角，彎矩就是撓度。

$$\theta=V^*,\qquad y=M^*$$

最大撓度發生在共軛梁剪力等於零（\(V^*=0\)）的地方，也就是從左端累積的彈性載重，剛好抵消左端共軛反力的位置；對稱載重時就在跨中。

桁架或剛架 → 單位力法：在要求位移的點、沿要求的方向加一個單位虛擬力，算出虛擬內力，再和真實變形相乘累加。

$$\Delta=\sum \bar n\,\frac{NL}{EA}$$

含沉陷／溫差／誤差

只要含有支承沉陷、溫差或製造誤差，一律用廣義虛功式：一乘 \(\Delta\)，加上虛擬反力乘支承移動的總和，等於虛擬桿力乘真實伸長的總和。

$$\underbrace{1\cdot\Delta+\sum \bar R_j\,\Delta_j}_{\color{#3b82b8}{\text{左：支承}}}=\underbrace{\sum \bar n_i\,e_i}_{\color{#3f9a55}{\text{右：桿件}}}$$

這條式子最重要的，是分清楚哪些量放左邊、哪些放右邊。桿件本身的變形，包括外力造成的 \(NL/EA\)、溫差造成的 \(\alpha\cdot\Delta T\cdot L\)、還有製造誤差，三者相加就是真實伸長 \(e\)，放在等號右邊：

$$e_i=\underbrace{\frac{N_iL_i}{EA}}_{\text{外力}}+\underbrace{\alpha\,\Delta T\,L_i}_{\text{溫差}}+\underbrace{\delta_i}_{\text{誤差}}$$
沉陷不進 e支承沉陷絕對不能放進 \(e\)，它是虛擬反力乘真實移動 \(\sum\bar R_j\Delta_j\)，放在等號左邊。

符號最容易出錯，建議獨立驗算：先只看沉陷，用幾何畫出剛體位移的直線，確認位移的大小和方向，再跟虛功式的結果比對。前面說過，靜定結構受沉陷只產生剛體位移，所以這條直線一定畫得出來。

獨立驗算只看沉陷 → 畫剛體位移直線 → 大小、方向都和虛功式一致才算對。

六題例題定位

用這棵決策樹來定位六題微型例題：

例題考點決策樹位置
① 靜不定度判定五種結構＋彈簧陷阱STEP 1
② 帶內鉸梁主附屬與內力圖STEP 2 求內力
③ 三鉸剛架受拉側與節點平衡STEP 2 求內力
④ 桁架零力桿與截面法STEP 2 求內力
⑤ 共軛梁法找最大位移STEP 3 外力
⑥ 虛功三成因疊加、反解 \(P\)STEP 3 非外力

易錯點

三個常見錯誤 ① 靜定結構受溫差或沉陷，還拿 \(EA\) 去算內力 → 正確答案是 0。
② 把支承沉陷寫進桿件伸長 \(e\) → 放錯邊，符號和數值都會錯；應放左邊 \(\sum\bar R\Delta\)（虛擬反力 × 沉陷）。
③ 帶內鉸梁先解主結構 → 內鉸力還不知道，解不下去；一定是先附屬、後主結構。

總結

整理一下，拿到題目先問三個問題：

步驟問題答案／方法
STEP 1靜定嗎？算 \(d\)；\(d<0\) 就回頭找隱藏條件
STEP 2要內力還是位移？內力只需要平衡：梁先附屬後主，桁架用零力桿＋截面法
STEP 3變形成因是什麼？只有外力：梁用共軛梁法，桁架剛架用單位力法；
含沉陷、溫差、誤差：用廣義虛功式
一句話串起整個單元靜定結構的內力唯一、而且與材料無關；位移才需要 \(EI\)、\(EA\)。
